# DesktopSpace

一个极简、零依赖、高性能的 **Windows 原生桌面 Dock 与浮层应用抽屉**（基于 C# + WPF + Win32 API，编译后主程序仅 ~120 KB）。

## 核心特性

- **原生毛玻璃浮动 Dock**
  - 居中自适应宽度与平滑增减动画，完全替代原生任务栏（内置 `--guard` 守护进程，意外退出时自动恢复原任务栏）。
  - 支持 **固定应用 1 秒长按圆环拖拽排序**，以及从桌面/资源管理器**直接拖入 `.exe` / `.lnk` / 文件夹固定**。
  - **三态运行指示条**：后台单窗口圆点、多窗口短胶囊、当前焦点深蓝长胶囊；配合 `EVENT_SYSTEM_FOREGROUND` 钩子实现 0 延迟高亮切换。
  - **DWM 实时多窗口并排预览**：悬停在运行中应用上自动展示实时缩略图（支持多窗口横向并排、点击激活、单独关闭窗口）。
- **效率增强的浮层应用抽屉（`Alt + Space` 全局呼出）**
  - 自动聚合个人桌面与公共桌面项目（排除已固定到 Dock 的应用），支持文件夹下钻、分类筛选与分页。
  - 支持 **中文拼音首字母搜索**（如输入 `wyy` 匹配“网易云音乐”）、鼠标滚轮翻页、`↑ ↓ ← →` 方向键选应用、`Tab` 切换分类、`Enter` 直接启动。
- **系统状态栏与快捷手势**
  - **真·输入框中/英 IME 状态同步**：直接读取焦点窗口输入法转换状态，点击即可切换中英文。
  - **音量快捷控制**：图标随静音自动切换，悬停滚轮直接调音量，中键一键静音，点击弹出独立“声音与音量”面板。
  - **网络与连接面板**：实时检测活动网卡状态，提供 Wi-Fi / 蓝牙 / 热点快捷入口。
  - **日历卡片**：点击 Dock 时钟弹出月历与实时秒表，支持一键呼出系统通知中心。
  - **开始按钮右键（Win+X 菜单）**：快速打开任务管理器、Windows 终端、系统设置、锁屏、睡眠、重启与关机。
- **全屏与多显示器智能躲避**
  - 支持 `智能躲避最大化/分屏`、`始终自动隐藏`、`始终显示` 三档模式，以及多显示器是否保留副屏原生任务栏开关。
  - 全屏游戏/视频下自动隐藏并开启鼠标穿透，按 `Win` 键或鼠标移至底边即可唤醒。

## 快捷键与鼠标手势

| 操作 | 效果 |
| --- | --- |
| `Alt + Space` | 全局呼出 / 收起“全部应用”抽屉 |
| `Win` 键（在隐藏 Dock 时） | 临时唤醒 Dock（不误触系统开始菜单） |
| 按住 Dock 固定图标 1 秒 | 出现圆环进度条，满 1 秒后左右拖动调整顺序 |
| 从桌面/文件夹拖入文件到 Dock | 直接将该应用或文件夹固定到 Dock |
| 鼠标悬停音量图标 + 滚轮 / 中键 | 直接调节系统音量 / 一键静音 |
| 鼠标悬停多窗口应用图标 + 滚轮 | 在该应用的多个窗口之间循环切换 |
| 鼠标中键点击应用图标 | 新开一个窗口（可在设置中改为关闭窗口） |
| 右键点击开始按钮 | 打开 Win+X 系统快捷与电源菜单 |

## 零依赖编译与运行

无需安装 Visual Studio，Windows 系统自带 `.NET Framework 4.x` 即可一键编译：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

编译产物位于 `bin\DesktopSpace.exe`。

### 常用命令行参数

- `bin\DesktopSpace.exe`：启动完整 Dock 模式
- `bin\DesktopSpace.exe --restore-taskbar`：一键退出 Dock 并恢复 Windows 原生任务栏
- `bin\DesktopSpace.exe --self-test`：运行自动化自检
